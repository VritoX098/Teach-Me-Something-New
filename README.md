# Teach Me Something New

A minimal Chrome Extension that removes decision fatigue: one click gives you something new to learn, chosen at random from curated categories.

## What it teaches  
Random Wikipedia article  
Random GitHub repository  
Random science fact  
Random historical event  
Random English word  
Random productivity tip  
Random AI tool  
Random programming concept  


## Install
1. Download the ZIP above and unzip it.  
2. Open chrome://extensions in Chrome, Edge, Brave, Arc, or any Chromium browser.  
3. Enable Developer mode using the toggle in the top-right.  
4. Click Load unpacked and select the unzipped folder.  
5. Pin the extension and click its icon whenever you're bored.  


## Privacy

Just uses the below api: 

- en.wikipedia.org
- api.github.com
- api.dictionaryapi.dev
